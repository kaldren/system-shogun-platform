# SystemShogun Design System

This is the binding source of truth for SystemShogun's frontend look-and-feel. The `frontend`
agent must read this file before writing any UI code and follow it, even when a spec is silent
on styling. If a spec's UI requirements conflict with this document, the frontend agent must
flag the conflict rather than silently picking one.
